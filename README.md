## Features

- Employee Goal Creation
- Quarterly Goal Tracking
- Goal Weightage Validation
- Progress Updates & Achievement Tracking
- Progress Percentage Bars
- Manager Approval Workflow
- Return for Rework
- Goal Locking after Approval
- Manager Review Comments
- Admin Dashboard
- Analytics Dashboard with Charts
- CSV Report Export
- Audit Logs
- Role-based Dashboards
